# Frontend Developer Test Assignment — Junior Level

## **Objective**

Assess the candidate's ability to quickly build and deploy a functional Web3 application using modern development tools, including AI-assisted development platforms.

---

## **Task Description**

Create and deploy a landing page with MetaMask wallet integration.

### **Functional Requirements**

1. **Wallet Connection**
    - Implement a "Connect Wallet" button
    - Handle MetaMask connection flow
    - Display appropriate states (connected/disconnected)
2. **Balance Display**
    - After wallet connection, display the user's ETH balance on Ethereum Mainnet
    - Display the user's USDT balance on Ethereum Mainnet
    - Balances should update upon connection
3. **Deployment**
    - The project must be deployed and accessible via a public URL

### **Design Requirements**

- Design and styling are at the candidate's discretion
- The interface should be clean, user-friendly, and responsive
